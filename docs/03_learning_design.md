# 学习设计

## 核心学习闭环

本项目采用以下学习闭环：

论文输入
→ AI 生成知识图谱
→ AI 分层讲解
→ 用户完成阶段任务
→ AI 诊断错误类型
→ AI 给出针对性反馈
→ 用户进行补救练习
→ 更新掌握状态
→ 进入下一阶段或迁移任务

该闭环对应课程要求中的：

输入 / 知识点
→ AI讲解
→ 用户尝试
→ AI反馈
→ 再强化 / 迁移

## AI 角色设计

### 1. 知识定位者

触发条件：用户上传论文后。

作用：
- 判断论文所属 AI 子领域；
- 提取核心概念；
- 生成知识图谱。

### 2. 方法拆解者

触发条件：用户进入“方法主线”阶段。

作用：
- 提炼输入、模块、流程、输出、优化目标；
- 帮助用户从细节中抽出方法主线。

### 3. 提问者

触发条件：每个学习阶段结束时。

作用：
- 生成阶段小任务；
- 促使用户主动复述、判断、比较和迁移。

### 4. 纠错者

触发条件：用户提交答案后。

作用：
- 判断用户错误类型；
- 给出针对性反馈；
- 生成补救任务。

### 5. 迁移训练者

触发条件：用户完成基础学习阶段后。

作用：
- 引导用户比较相似论文；
- 引导用户思考方法迁移到其他任务的可能性。

## 错误类型与反馈策略

### E1 领域归类错误

表现：
用户把论文所属领域判断错误，例如把持续学习误认为迁移学习。

反馈策略：
- 对比两个领域的目标、数据设定和训练方式；
- 指出本文为什么属于某个领域；
- 要求用户重新说明判断依据。

### E2 概念混淆错误

表现：
用户混淆两个相近概念，例如 catastrophic forgetting 和 overfitting。

反馈策略：
- 分别给出两个概念的定义；
- 给出论文中的对应位置；
- 要求用户用一句话区分二者。

### E3 方法流程错误

表现：
用户遗漏关键模块，或者说不清输入、步骤、输出。

反馈策略：
- 给出方法流程骨架；
- 标出用户遗漏的步骤；
- 要求用户补全流程。

### E4 公式理解错误

表现：
用户只认识符号，但不知道公式每一项的作用。

反馈策略：
- 拆解公式每一项；
- 解释每一项对应的训练目标；
- 要求用户重新解释公式为什么有用。

### E5 实验解读错误

表现：
用户看不懂主实验、消融实验和对比实验的作用。

反馈策略：
- 说明不同实验类型的目的；
- 指出该实验验证了哪个 claim；
- 要求用户重新判断实验结论。

### E6 贡献误判错误

表现：
用户把已有方法当作本文创新，或者夸大论文贡献。

反馈策略：
- 区分已有工作、本文改进和真正贡献；
- 要求用户重新总结核心贡献。

### E7 迁移能力不足

表现：
用户读懂单篇论文，但无法迁移到相似问题或新任务。

反馈策略：
- 给出一个相似场景；
- 引导用户判断哪些模块可迁移、哪些模块需要修改。
