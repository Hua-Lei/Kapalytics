# v0.2 Three-Column Learning Workbench

## Goal

Build interactive three-column layout with tab switching, learning path display, and reactive right panel.

## Design Decisions

- **Tab style**: Segmented control (Design B) — compact toggle in center panel header
- **Stage status colors**: Green (completed), Red (in progress), Gray (not started)
- **State management**: React `useState` in App, no external library needed

## Components

```
App
├── LeftPanel          — PDF placeholder
├── CenterPanel
│   ├── TabBar         — Segmented "知识图谱 | 学习路径"
│   ├── GraphView      — Placeholder (v0.3)
│   └── LearningPath   — 7 stage list with status badges
└── RightPanel         — Stage detail when selected
```

## Types

- `StageStatus`: `'not_started' | 'in_progress' | 'completed' | 'needs_review'`
- `Stage`: `{ id, order, name, status, description }`
